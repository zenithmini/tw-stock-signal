# 台股進場判斷器

一個可直接部署到 GitHub Pages、適合手機使用的台股 PWA。系統先以加權指數判斷整體市場，再分析輸入的上市股票或 ETF，最後輸出可解釋的進場與風險判斷。線上版以 FinMind 公開日線 API 為主要資料來源，並保留證交所端點作為備援。

## 功能

- 支援證交所上市股票與 ETF（例如 `0050`、`2330`）
- 先檢查加權指數收盤、MA25／MA99 排列與 MA99 二十日斜率
- 大盤多頭使用完整部位、中性自動減半、空頭停止新的多方進場
- 計算 MA7／25／99、RSI14、KD(14,3,3)、MACD(12,26,9)、ATR14、20 日均量
- 六道檢查：趨勢、價格結構、回檔、轉強、禁止追價、流動性
- 顯示參考進場價、2ATR／近期低點停損、3R 目標價
- 依資金、單筆風險與單檔上限計算張數／零股
- 自選股、最近分析與離線快取只保存在使用者手機瀏覽器
- PWA，可加入手機主畫面

## 部署到 GitHub Pages

1. 在 GitHub 建立一個空白 repository，例如 `tw-stock-signal`。
2. 將本專案所有檔案上傳到 repository 的 `main` 分支。
3. 到 **Settings → Pages → Build and deployment**，將 Source 選為 **GitHub Actions**。
4. 等待 Actions 裡的 `Deploy GitHub Pages` 完成。
5. 網址會是 `https://你的帳號.github.io/你的-repository-名稱/`。

之後只要 push 到 `main`，GitHub Actions 會自動重新建置與部署。建置流程會將資源網址改成相對路徑，因此 repository 名稱不需固定。

## 本機執行

需要 Node.js 22：

```bash
npm ci
npm run dev
```

建立 GitHub Pages 用的正式靜態網站：

```bash
npm run build:pages
```

GitHub Pages 使用的靜態檔會在 `dist/client`。

## 策略摘要

第一步先判斷加權指數：

- 多頭：指數站上 MA99、MA25 高於 MA99、MA99 二十日斜率向上，允許 100% 設定部位。
- 中性：三項條件多空交錯，個股觸發時只允許 50% 設定部位。
- 空頭：三項條件全部未通過，停止所有新的多方進場。

第二步才檢查個股：

1. `MA25 > MA99`，且 MA99 最近五日沒有明顯下彎。
2. 收盤價必須站在 MA99 之上。
3. 價格接近 MA25、RSI 回到 42–58，或 KD-K 低於 35，至少符合一項回檔條件。
4. 收盤站回 MA7、MACD 柱狀體增強，且 KD 或價格轉強；放量突破 20 日高點可作為替代觸發。
5. RSI 不得過熱，價格也不能偏離 MA25／MA99 太遠。
6. 20 日均量至少 20 萬股。

停損取「近期 10 日低點下一個跳動單位」與「進場價減 2ATR」之中較接近的價格，若停損距離超過 8% 則不進場；目標價為 3R。部位計算含買賣手續費，股票賣出稅以 0.3%、ETF 以 0.1% 估算。

## 已知限制

- 目前只支援證交所上市市場；上櫃股票需改接櫃買中心資料。
- 使用證交所原始成交價，不是還原股價。除權息、分割後需人工確認；系統偵測到近 100 日超過 15% 的跳空時會停止給進場訊號。
- 日線收盤後分析，不是盤中即時報價，也不會連接券商自動下單。
- 加權指數與個股都採收盤日線；不是盤中大盤燈號。
- FinMind 匿名 API 有每小時使用額度，個人正常查詢通常足夠；若資料來源或網路暫時不可用，網頁只會使用這台裝置近期成功分析的快取，沒有可靠的大盤資料時不提供新訊號。

## 風險聲明

本工具是規則化研究與風險管理輔助，不是投資建議、報酬保證或自動下單服務。實際交易前仍需評估個人財務狀況、公司事件、除權息與市場流動性。
